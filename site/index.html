Проверьте API прямо здесь

Откройте метод, нажмите Try it out, затем Execute. Исходный FastAPI работает в Python внутри браузера. Данные доступны только в этой вкладке и сбрасываются при перезапуске. Ответы МИС и платежи имитируются; уведомления не отправляются.

Начните с GET /api/v1/doctors, выберите врача и получите его слоты. Для записи используйте свободный slotId. Тестовый пациент уже авторизован.

Адрес medlink.local в примерах — виртуальный адрес этой демонстрации. Он работает только через кнопку Execute на странице. Чтобы отправлять запросы из терминала, запустите API локально по инструкции в репозитории.

Загрузка Python… Первый запуск загружает среду выполнения и может занять несколько минут.

Сброс восстанавливает тестовые записи и расписание на ближайшие 7 дней. Служебные токены описаны ниже.
